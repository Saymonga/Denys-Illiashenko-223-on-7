# Denys-Illiashenko-223-on-7
ПРАКТИЧНА РОБОТА № 7 Порівняння Parallel vs Sequential I/O (eu-node-basics-workshop)
Practice 7 - Parallel vs Sequential I/O
Мета роботи

Навчитися працювати з асинхронними операціями в Node.js, зрозуміти різницю між послідовним та паралельним виконанням, а також вплив threadpool на продуктивність.

Як запустити
Відкрити термінал у папці з файлами.

Виконати команду:

node <назва_файлу>.js 3000

Перевірити роботу через браузер або curl:

http://127.0.0.1:3000/

Виконані вправи
7.1 Sequential File Reads — послідовне читання файлів
7.2 Parallel Reads — паралельне читання через Promise.all
7.3 Handle Partial Failures — обробка помилок через Promise.allSettled
7.4 Threadpool Limit — виконання 8 асинхронних задач через crypto.pbkdf2
Перевірка

Для перевірки використано:

npx eu-node-basics-workshop

Усі вправи пройдені та мають статус [COMPLETED].
